# ACS 2024 curated city profile fixture

This directory contains a small source-backed Stage 3.2 fixture for five demo cities. Values are transcribed from official U.S. Census Bureau 2024 ACS 1-Year profile pages on data.census.gov.

Fields used:
- bachelor's degree or higher (%)
- median household income (USD)
- employment rate (%)

Reference pages:
- New York, NY: https://data.census.gov/profile/New_York_city,_New_York?g=160XX00US3651000
- Los Angeles, CA: https://data.census.gov/profile/Los_Angeles_city,_California?g=160XX00US0644000
- Chicago, IL: https://data.census.gov/profile/Chicago_city,_Illinois?g=160XX00US1714000
- Houston, TX: https://data.census.gov/profile/Houston_city,_Texas?g=160XX00US4835000
- Phoenix, AZ: https://data.census.gov/profile/Phoenix_city,_Arizona?g=160XX00US0455000

The fixture is intentionally curated and small so ETL/evaluation remain reproducible. It is not a complete ACS extract.
